iR

A shell interface shaped for Linux workflows

iNiR is a Quickshell-based shell environment for Linux, focused on Niri and Arch. Built with modularity and composability in mind, it helps you craft a calm, keyboard-first desktop that stays out of your way.

  anchors { top: true; left: true; right: true }

  color: "#e2e3d7cc"
